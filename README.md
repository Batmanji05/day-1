## GitHub Workflow

This is the official Week-1 Day-1 repository of Solarpunk Corps.

Each team will:

1. Fork the official repository to its own GitHub account.
2. Clone its fork and work locally.
3. Use the assigned team folder.
4. Write and save all work inside that folder.
5. Push the completed work to its own fork.
6. Submit the work through a Pull Request to the official Solarpunk Corps repository.

The detailed tutorial explains the complete Git and GitHub workflow.

---

## Team Folder

Each team will have its own folder:

```text
Day-1/
├── README.md
├── starter-codes/
├── Team-01/
├── Team-02/
├── Team-03/
└── ...
```

**Your team must work only inside its assigned folder.**

Do not modify, delete, or place files inside another team's folder.

Keep your code and supporting files organized within your own team directory.

## Submission

Before submitting, make sure your team's work:

- Is inside the correct team folder.
- Is complete and tested.
- Does not interfere with another team's work.
- Has been pushed to your GitHub fork.

Then create a Pull Request from your fork to the official Solarpunk Corps **Day-1** repository.

Use a clear title such as:

```text
Team-01 Day 1 Submission
```

Include your:

- Team name
- Team members
- Brief description of the submitted work

The organizers will review the Pull Request before merging it.
