## General Instructions

Welcome to Week 2, Day 1 of the Solarpunk Corps technical program.

Before starting the session, make sure your laptop has the required software and accounts properly set up.

### Required Setup

You should have the following installed and ready:

- Python 3
- Git
- Visual Studio Code
- A GitHub account
- Internet connection
- Required Python libraries as specified during the session

If Python, Git, VS Code, or any required library is not installed or working correctly, refer to the provided **Day 1 Tutorial & Submission Guide** for setup and troubleshooting instructions.

The tutorial also contains the required information about Python, pip, Git, GitHub, repositories, forks, commits, pushes, and Pull Requests.

---

## GitHub Repository

The official Day-1 repository will be provided by the Solarpunk Corps organizers.

You will be required to:

- Fork the official repository to your own GitHub account.
- Work on your own fork of the repository.
- Create a folder specifically for your team.
- Keep all of your team's work inside that folder.
- Push your changes to your own fork.
- Submit your work through a Pull Request to the official Solarpunk Corps repository.

---

## Team Folder

Each team must create and use its own folder.

For example:

```text
Day-1/
├── README.md
├── starter-codes/
│
├── Team-01/
├── Team-02/
├── Team-03/
└── ...
```

### Important

**Write your code and store your files inside your assigned team folder only.**

Do not:

- Modify another team's folder.
- Delete another team's files.
- Place your code in another team's folder.
- Modify the repository structure unnecessarily.
- Overwrite or interfere with starter/reference files unless instructed to do so.

Keep your team's code, supporting files, and other required work inside your own team folder.

---

## Starter Codes

The `starter-codes/` directory contains **reference and starter code** for the activities.

Use these files to understand the expected structure and concepts before developing your own solution.

Do not modify the starter/reference code unless specifically instructed during the session.

## Python Libraries

Some activities may require additional Python libraries.

Install only the libraries specified by the instructors or mentioned in the provided tutorial.

Make sure the required libraries are installed and working before starting the activity.

---

## Code Submission

Your team's final work must be available in your assigned team folder.

Before submitting, make sure:

- Your code runs correctly.
- Your files are inside the correct team folder.
- You have not modified another team's work.
- Your changes have been committed.
- Your changes have been pushed to your GitHub fork.
- Your Pull Request is created against the official Day-1 repository.
- Your Pull Request clearly identifies your team and team members.

---

## Pull Request

After completing your work, create a **Pull Request** from your fork to the official Solarpunk Corps Day-1 repository.

Use a clear title, for example:

```text
Team-01 Day 1 Submission
```

Include your:

- Team name
- Team members
- Brief description of the submitted work

The Solarpunk Corps organizers will review the Pull Request before merging it.

---

## Important Rules

1. Work only inside your assigned team folder.
2. Do not modify or delete another team's work.
3. Do not unnecessarily change the repository structure.
4. Do not upload passwords, API keys, tokens, or other private credentials.
5. Keep your code organized and readable.
6. Use clear file names and commit messages.
7. Test your code before submitting.
8. Submit your completed work through a Pull Request.
9. Follow the detailed instructions provided by the instructors and the Day 1 Tutorial & Submission Guide.
