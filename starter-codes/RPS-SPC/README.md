# Rock-Paper-Scissors vs a "Learning" Computer

A beginner Python project built during Solarpunk Corps (SPC)'s Foundation
Program. It's classic Rock-Paper-Scissors, but the computer tracks your
move history and predicts your next move instead of choosing randomly —
a simple, honest first taste of prediction-based "AI" logic.

## Features
- Interactive rock/paper/scissors gameplay in the terminal
- Computer predicts your next move based on your most common past move
- Running score (wins / losses / ties) across the whole session

## How to Run
1. Make sure Python 3 is installed.
2. Clone this repository:
   git clone https://github.com/<your-username>/<repo-name>.git
3. Run the program:
   python rps_ai.py
4. Type `rock`, `paper`, or `scissors` each round, or type `quit` to stop
   and see your final score.

## Example
Input:  rock
Output: Computer played: paper — Computer wins this round!
